# match-social-pdfs

PDFs de las presentaciones de Match Social, generados por la rutina cloud.
Enlazados desde la tabla Propuestas de Airtable.

- `pdfs/<Código>.pdf` — ej. `pdfs/MS-CLB-001.pdf`
- `pdfs/tipo/<key>.pdf` — plantillas por tipo de público (cliente, empresa, marca, clubes, clubes_aliado, proveedor, tienda, seccion_general).

Público a propósito: son los mismos PDFs que se le mandan a los clientes.
Todo lo demás (código, business plan, precios) vive en el repo privado `match-social`.
